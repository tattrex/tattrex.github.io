# Interaction motion refinement

The user wants every instruction to stand out before its result blends back into the scan, with a spectrum that changes with the utterance. This is a scoped refinement of the approved image and voice prototype, preserving the real CPAISD data, dotless logo, hero, Labs artwork and absence of viewer chrome.

Use a three beat sequence: simulated utterance, response, settling. Following the user's latest clarification, the website is entirely silent: no narration, microphone capture, speech recognition, audio controls or audio assets. The guided spectrum uses stored visual cadence profiles, including silence. Custom typed instructions use a text cadence. These profiles do not access browser audio APIs.

The emphasis is specific to the operation: window values interpolate; masks reveal on their actual voxel boundaries, briefly strengthen then return to the existing opacity; a MIP gathers a shallow stack into its projection; MPR planes unfold; the prior arrives alongside the current scan; comparison briefly brackets the corresponding ventricular region; reporting emphasizes the response while retaining the scan. Transforms always move image and annotation together. No invented lesions, detached masks or false quantitative findings.

The builder chooses timing within a 7.5 second tour beat: approximately 1.5–3 seconds speaking, 0.7 seconds emphasis, 1.5 seconds settling, then quiet inspection. Chapter selection replays that moment. Typed input responds immediately. Pause freezes the motion; resume continues it. New instructions, restart, visibility changes and reduced motion must cancel stale callbacks. Reduced motion applies the final result without spatial animation and retains readable feedback.

Use the live prototype for precise audio and canvas timing; add editable key poses and motion guidance to Figma for review. No publication or site wide redesign is part of this iteration.
