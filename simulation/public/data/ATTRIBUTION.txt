The data contain real anonymized non-contrast CT slices and expert masks.
Labels: 0 = background, 1 = ischaemic core, 2 = penumbra.
The dataset paper describes annotation by a radiologist with ten years of
experience using CT perfusion maps as reference.

Modifications for the Tattrex review prototype:
- DICOM pixel rescale slope/intercept applied to obtain HU; matched original
  published image.npz values exactly before preparation.
- CT and masks sampled at identical native voxel centres, every second
  in-plane voxel. No mask smoothing, new lesion, or lesion attenuation change.
- Sorted by DICOM patient position, flipped from LPS into canonical RAS.
- Arrays encoded as little-endian Int16 HU and Uint8 labels, gzip compressed.
- Display windowing, MIP/MPR and coral/gold overlays are presentation operations.
- The prior is an explicitly derived illustration with a smooth local
  ventricular deformation. It is not a source follow-up scan. current.raw.gz
  retains source pathology. No actual interval change is represented.
- prior-delta.raw.gz stores the prior as a lossless 16-bit XOR against
  current.raw.gz, followed by gzip. Decoding restores the exact prior voxels.

The UI actions are scripted. Masks are dataset reference annotations, not
Tattrex model predictions. No endorsement by the dataset creators is implied.
Source-file hashes are recorded in source-manifest.json.
