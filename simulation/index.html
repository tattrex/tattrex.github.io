Image source and reference annotations

Real CT and expert reference masks: Umerenkov, Kudin, Peksheva and Pavlov (2024), CPAISD: Core-Penumbra Acute Ischemic Stroke Dataset, CC BY 4.0. The source includes radiologist-drawn stroke-core and penumbra annotations, informed by CT perfusion. The highlighted mask is a published reference annotation, not a Tattrex model prediction.

The source CT and masks are sampled at identical voxel positions for web display; orientation is preserved. No lesion is invented or painted into the current CT. Windowing, 15 mm MIP and MPR operate on this volume. The priority and report actions are scripted. The dataset has no real earlier examination, so the comparison companion is an explicitly derived illustrative prior with a local ventricular deformation. It does not demonstrate real interval change.
